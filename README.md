# Kyros Agenda

PWA da Kyros Tech para agenda, clientes, servicos e mensagens de WhatsApp para saloes e barbearias.

## Deploy na Vercel

Configuracao recomendada:

- Framework Preset: Other
- Root Directory: `kyros-agenda`
- Build Command: vazio
- Output Directory: `public`

Depois do deploy, apontar o dominio:

```text
agenda.kyrostech.com.br
```

## Desenvolvimento local

```bash
npm install
npm run dev
```
